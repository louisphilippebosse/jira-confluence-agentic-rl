# Skill: jql-optimizer

## Purpose
Wraps and enhances the existing `JiraQueryBuilder` to create better, more reliable JQL queries.

## What It Does

### Input
- User query
- Initial JQL (from JiraQueryBuilder)
- Query analysis (from query-analyzer skill)

### Processing
1. Validate JQL syntax (quote multi-word values)
2. Add time-based filters if needed
3. Create fallback query (broader search)
4. Optimize field selection for performance
5. Add ORDER BY for relevance

### Output
```python
{
    "primary_jql": 'type=Bug AND status="In Progress" AND updated >= -7d ORDER BY updated DESC',
    "fallback_jql": 'type=Bug AND status="In Progress" ORDER BY updated DESC',
    "validation": {
        "syntax_valid": True,
        "estimated_results": "10-50",
        "performance_score": 0.85
    },
    "strategy": "time_filtered_with_fallback"
}
```

## Integration Point

**Before**: `JiraQueryBuilder.build_jql_from_keywords()` sometimes generates invalid JQL
**After**: Validates and optimizes before execution

```python
# In ai_agent_service._intelligent_jira_search()
initial_jql = self.query_builder.build_jql_from_keywords(message)

if use_skill_enhancement:
    optimized = await skill_middleware.execute("jql-optimizer", message, initial_jql, analysis)
    jql_to_execute = optimized["primary_jql"]
    fallback_jql = optimized["fallback_jql"]
```
